# WINORWINS – Origin Story section

Interactive "The Making of Origin Story" section (accordion, 6 steps: Idea → Moodboard → Techpack → First Sample → Bulk → Final Piece).

- `index.html` – the whole section: HTML, CSS and JavaScript in one file, no dependencies.
- `images/` – all photos and sketches used in the steps.

Open `index.html` in a browser to preview.

## Editing
- Texts, step names and images: the `steps` list in the `<script>` at the bottom of `index.html`.
- Accent colour: `--accent` at the top of the `<style>` (default `#FEDD00`).
- Button link: `href` of `.os-cta` (default `/collections/all`).
- If the images are hosted elsewhere (e.g. Shopify Files), change `IMG` in the script to that URL prefix.
